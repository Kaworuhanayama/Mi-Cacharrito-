# Mi_Cacharrito_Proyecto_Completo

Proyecto Maven + Spring Boot para Eclipse.

Estructura principal:

Mi_Cacharrito_Proyecto_Completo/
├── pom.xml
├── src/
│   ├── main/
│   │   ├── java/Mi_Cacharrito/
│   │   │   ├── modelo/
│   │   │   ├── repositorio/
│   │   │   └── controlador/
│   │   └── resources/
│   │       ├── application.properties
│   │       └── static/
│   └── test/java/Mi_Cacharrito/
└── target/

Nota: target/ es generado automáticamente por Maven y no debe subirse a GitHub.
